## ✨ Key Features

* **➕ Add Tasks:** Quickly add new tasks to your daily list.
* **🔍 Search Tasks:** Instantly filter and find specific tasks in real time.
* **✏️ Edit Tasks:** Update existing task descriptions on the fly.
* **🗑️ Remove Task:** Easily delete individual completed or unwanted tasks.
* **🧹 Remove All Tasks:** Clear your entire task list with a single click.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic markup for an accessible layout.
* **Tailwind CSS:** Utility-first CSS framework for clean, responsive design.
* **JavaScript (Vanilla ES6+):** Modern DOM manipulation and event handling without external libraries.
